# Iconos de escritorio

`logo.png` en la raíz se conserva intacto. Estas variantes se editaron con la herramienta integrada ImageGen; no se regeneran al compilar. El empaquetado convierte los PNG a los formatos nativos.

- `macos.png`: fondo blanco redondeado y margen transparente.
- `windows.png`: letras sin fondo; compartido con Linux.

## Instrucciones usadas en ImageGen

### macOS

Edit target: logo.png. Create a production macOS app icon from this EXACT TFG logo. Preserve the original blue/cyan/green glass TFG letter artwork faithfully: same letter shapes, order, colors, highlights, relative size and composition. Do not redesign or add any elements. Change ONLY the outer white background shape: make it a clean white macOS-style continuous rounded square (squircle), inset about 10% on all four sides of a square 1024x1024 canvas, with smooth generously rounded corners. Scale the complete original square artwork down uniformly to fit this tile, centered. Outside the tile must be genuinely fully transparent alpha, including canvas corners and margin. Keep white behind and between the letters inside the tile. Straight-on flat icon asset, no perspective, no device mockup, no outline, no added shadow, no checkerboard drawn into image, no new text. Text exactly TFG.

Limpieza posterior del resultado:

Precise alpha-channel cleanup ONLY of the provided macOS icon asset. Keep the existing logo, letter shapes, colors, size, location, and white rounded-square tile unchanged. Make the tile outer edge a mathematically clean smooth continuous curve with antialiasing and a perfectly regular symmetric rounded-square silhouette. Remove ALL white specks, stray pixels, ragged bits, dots, holes, detached fragments, grime and fuzzy alpha outside the tile. There must be exactly one opaque white rounded square containing the original TFG artwork, with completely transparent outer margins, no extra objects. Canvas is square, no black/white/checkered background outside tile. Do not alter or regenerate artwork inside the tile.

### Windows

Edit target: logo.png. Create a transparent Windows app icon by removing ONLY the white background from this existing TFG logo, including all white gaps between and within the letters. Preserve the original blue/cyan/green glass TFG lettering faithfully: identical shapes, letter order, colors, gradients, reflections, highlights and texture. Keep the glass highlights INSIDE the letters. Do not redraw, restyle, change typography, add shadows or add a tile. The output should contain ONLY the complete three original TFG letters with clean anti-aliased alpha edges on a genuinely fully transparent square 1024x1024 canvas. Center the group and size to occupy about 90% of canvas width without clipping any letter. No white rectangle, no border, no checkerboard drawn in image, no extra text. Text exactly TFG.
